## 5. Test fragility (typing before async loads settle)

| site | shape | risk |
|---|---|---|
| PlaygroundPage.test.tsx:31-47 (test 1) | `await waitFor(run-as text)` then `user.type` | OK: waits on the auth label, but `getMe` -> `setAgentId` and the `ToolRunner key={id:schemaHash}` can remount the form if `schemaHash` changes between list and detail (same hazard class); fine with the mock (B). |
