## 5. Suite-health proposal

Goal: `pytest -n auto` safe, deterministic, <3 min locally, same in CI.

1. **Per-worker database (recommended)** — in `conftest.py` add `pytest_configure_node`/session fixture reading `PYTEST_XDIST_WORKER`: connect to the admin DB, `CREATE DATABASE mcprouter_test_gwN TEMPLATE mcprouter_test_template`. Build the template ONCE per run: `CREATE EXTENSION vector`, `init_db`, then freeze. Each worker's `settings.database_url` points at its DB; the template removes per-test DDL (A6-040). Test-level isolation inside a worker: run each test in an outer transaction with SAVEPOINT (`join_transaction_mode="create_savepoint"`) — works for sync `Session` tests; tests that open uvicorn threads or separate sessions need real commits, so for those keep `TRUNCATE … CASCADE` of `sorted_tables` (A6-041 fix) on teardown. Alternative: **schema per worker** (`SET search_path`, `CREATE SCHEMA w{N}`) is cheaper than a database but the raw-SQL and `pgvector`/`ix_tools_fts` DDL in `retriever.py:138-168`, `db.py:52`, and advisory-lock keys (`rollup.py:30`, global per database!) are not schema-scoped — per-worker DATABASE avoids all of that. Note the advisory lock key is DB-wide: two workers sharing one DB would serialise or deadlock rollup tests.
2. **Safety guard**: refuse to run unless the DB name matches `*_test*` (A6-042) — the suite DELETEs whole tables.
3. **Port allocation helper** `tests/support/ports.py::free_port()` (bind to 0, close, return; or better: pass an already-bound socket to `uvicorn.Server.serve(sockets=[sock])` to avoid the TOCTOU). For the testbed fleet make `http_fleet(port_base=None)` allocate N consecutive free ports and return `urls`; replace all literals in section 2 except dead-port tests, which should bind-then-close a socket to guarantee "nothing listens". Add `tests/support/serve.py::run_app` replacing 5 copies.
4. **Marker policy** (register + `--strict-markers`): `db` (auto), `e2e` (uvicorn/subprocess/fleet), `slow` (real models, `MCPR_RUN_SLOW`), `scale` (testbed_scale, perf). CI jobs: `unit` = `-m "not e2e and not slow and not scale" -n auto`; `e2e` = `-m e2e` (serial or xdist `--dist loadfile`); nightly = `slow + scale` with inference extra and `models-cache/` restored. Add `-ra`, `--durations=25`, `pytest-timeout`.
5. **Determinism**: replace sleeps with `wait_for` + events; clock-inject `RateLimiter`/engine idle (already supported); reset module-global state with an autouse fixture (feedback `LIMITER`, `get_process_engine`, dev-warning flag `_reset_dev_warning_for_tests`) instead of per-file `.clear()`.
6. **Support layout**: `tests/support/{db,serve,ports,fakes,seed}.py`, no `test_` prefix, fixtures exported via `pytest_plugins = ["tests.support.db", ...]` — removes all 17 cross-test-module imports (A6-043).
7. Sequence for low risk: (a) A6-041 table list + guard, (b) template DB + session-scoped init, (c) ports, (d) xdist behind a CI flag, compare pass counts with serial for two runs, (e) flip default.
