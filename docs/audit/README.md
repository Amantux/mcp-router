# docs/audit — point-in-time audit outputs, not operator docs

Each file here is the raw output of one review pass (the A1–A7 track audits,
the CI gripe lists, the fresh-eyes sweeps and the punch list that tracked their
fixes). They record what a reviewer saw at one commit, so line numbers and
claims go stale as soon as the findings are fixed.

They are **not** maintained and are not instructions. For running, configuring
or operating the router, use the docs one level up (`docs/INSTALL.md`,
`docs/deploy.md`, `docs/security-model.md`, …) and the top-level `README.md`.
What actually changed in each release is in `CHANGELOG.md`.
