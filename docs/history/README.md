# docs/history — archival, not operator docs

These files are the build-era record of MCP Router: per-track and per-wave
integration notes (`INTEGRATION_NOTES-*.md`) and the skills design plan
(`skills-plan.md`). They explain *why* the code looks the way it does at the
time each wave landed, and source comments cite them for that reason.

They are **not** maintained and may describe behaviour that has since changed.
For running, configuring or operating the router, use the docs one level up
(`docs/INSTALL.md`, `docs/deploy.md`, `docs/security-model.md`, …) and the
top-level `README.md`.
